# Reshma's Diet Care

GitHub Pages-ready responsive diet/nutrition website.

## Connect the client form to your email
This version uses Web3Forms, which provides an HTML form endpoint without your own server. Create a form at Web3Forms, verify your email, copy the Access Key, then replace `YOUR_WEB3FORMS_ACCESS_KEY` in `index.html`. Web3Forms currently lists 250 submissions/month on its free plan.

## Publish
Upload `index.html` and `style.css` to the repository. In GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

The form contains optional medical/diagnosis, medication and allergy fields. Treat that information as sensitive and provide clients with your privacy/retention information.
